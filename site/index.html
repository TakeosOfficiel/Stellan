Conçu pour travailler

Un véritable environnement de développement local.

Stellan ne se contente pas de répondre. Il peut parcourir le projet, écrire les fichiers, lancer les commandes et vous présenter précisément ce qui a changé.

Agent de programmation

Lecture, édition, terminal, Git, tests et aperçu web réunis dans le même espace.

Modèles locaux

Stellan installe Ollama, recommande le bon modèle et exploite automatiquement votre GPU.

Données privées

Conversations, modèles et projets restent stockés localement, sans service d’inférence cloud.

Workers parallèles

Les tâches indépendantes peuvent être confiées à plusieurs conversations isolées puis réunies.

Runtime intégré

Docker privé est géré en arrière-plan sous Windows comme sous Linux, sans installation externe.

Toujours à jour

Les versions sont vérifiées au lancement et téléchargées sans toucher à vos modèles ou projets.
