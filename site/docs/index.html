Documentation Stellan

Installez votre agent local, préparez un modèle et commencez à travailler sur vos projets en toute confidentialité.

Introduction

Stellan est un agent de programmation local pour Windows et Linux. Il utilise des modèles Ollama exécutés sur votre ordinateur et dispose d’outils pour lire, modifier et tester un projet.

Local par conceptionLe contenu de vos conversations, vos modèles et vos projets n’est pas envoyé à un service d’inférence cloud.

L’application prépare elle-même son moteur de conteneurs privé. Vous n’avez pas besoin d’installer Docker Desktop ou Docker Engine séparément.

Prérequis

WindowsLinux
SystèmeWindows 10/11 x64Distribution x86_64 récente
Mémoire8 Go minimum, 16 Go recommandés
StockageAu moins 12 Go libres, davantage selon les modèles
GPUOptionnel. NVIDIA recommandé pour les meilleures performances

Une connexion internet est nécessaire pour le premier téléchargement du runtime et des modèles, puis pour vérifier les mises à jour. L’inférence reste locale.

Installer sur Windows

  1. Téléchargez l’installateur Windows.
  2. Ouvrez le fichier puis choisissez le dossier d’installation.
  3. Au premier lancement, acceptez l’activation de WSL 2 si Stellan la demande.
  4. Redémarrez Windows si l’activation de WSL 2 l’exige, puis relancez Stellan.

Avertissement SmartScreen

Pourquoi cet avertissement ?La version actuelle n’utilise pas de certificat Authenticode payant. Le fichier est distribué depuis le serveur officiel de Stellan, mais Windows affiche donc « Éditeur inconnu ».

Dans la fenêtre SmartScreen, cliquez sur Informations complémentaires, vérifiez que le fichier s’appelle bien Stellan-0.1.4-win-x64.exe, puis choisissez Exécuter quand même.

Installer sur Linux

Stellan est distribué sous la forme d’une AppImage autonome.

  1. Téléchargez l’AppImage.
  2. Ouvrez un terminal dans le dossier de téléchargement.
  3. Rendez le fichier exécutable puis lancez-le.
chmod +x Stellan-0.1.4-linux-x86_64.AppImage
./Stellan-0.1.4-linux-x86_64.AppImage

Dépendances du runtime privé

Sur Ubuntu ou Debian, installez les outils nécessaires à Docker rootless puis reconnectez votre session :

sudo apt update
sudo apt install uidmap iptables

Pour un GPU NVIDIA, le pilote et NVIDIA Container Toolkit doivent être présents sur le système hôte. Stellan s’occupe ensuite de son daemon Docker privé : n’installez pas Docker Engine pour lui.

Premier démarrage

Stellan détecte le processeur, la mémoire et le GPU, prépare son runtime puis démarre Ollama sur une adresse locale. Cette préparation peut prendre plusieurs minutes, particulièrement lors du premier téléchargement.

  1. Laissez la fenêtre de progression terminer la préparation.
  2. Ouvrez Modèles.
  3. Sélectionnez un modèle adapté à votre mémoire.
  4. Attendez la fin de son téléchargement avant d’ouvrir un projet.
Premier message plus lentLe premier message après un démarrage charge le modèle en mémoire CPU ou GPU. Les réponses suivantes sont normalement beaucoup plus rapides.

Choisir un modèle

Le catalogue classe les modèles par usage : rapide, général, code, vision et image. Les recommandations tiennent compte de la mémoire détectée, mais le choix final vous appartient.

  • Choisissez un petit modèle pour une réponse rapide et une faible consommation.
  • Choisissez un modèle orienté code pour les modifications complexes.
  • Un modèle de vision est sélectionné automatiquement lorsqu’un message contient une image.
  • Les modèles restent dans le volume privé de Stellan et survivent aux mises à jour.

Projets et workers

Un projet est obligatoire pour utiliser l’agent. Chaque conversation principale dispose d’un worktree Git isolé afin de ne pas modifier directement votre dossier de départ.

Outils disponibles

  • Exploration et recherche dans les fichiers ;
  • création, modification et suppression contrôlée ;
  • commandes et tests dans un conteneur persistant ;
  • terminal interactif, diff Git et aperçu web ;
  • workers parallèles lorsque des fichiers indépendants peuvent être traités séparément.

Les workers sont créés par le coordinateur lorsque cela accélère réellement la tâche. Ils ne doivent pas modifier le même fichier simultanément.

Voix et images

Le bouton microphone enregistre jusqu’à une minute et transcrit localement avec Whisper. Le modèle de dictée, d’environ 750 Mo, est téléchargé une seule fois puis conservé en cache.

Vous pouvez également coller, déposer ou sélectionner jusqu’à quatre images PNG, JPEG ou WebP par message. Stellan choisit un modèle de vision déjà installé ou propose son téléchargement.

Mises à jour

Au lancement, Stellan vérifie automatiquement la version publiée sur update.stellan.takeos.fr. Lorsqu’une nouvelle version existe, elle est téléchargée puis installée avant le démarrage du runtime.

Vos données sont conservéesUne mise à jour de l’application ne supprime ni les modèles Ollama, ni les projets, ni les runtimes privés.

Si la vérification échoue, vérifiez la connexion internet puis relancez Stellan. Une mise à jour obligatoire ne peut pas être ignorée.

Données et confidentialité

Les conversations sont stockées dans une base SQLite locale. Les modèles résident dans le volume Ollama du runtime privé et les environnements de travail restent sur le disque de l’ordinateur.

Les connexions internet servent aux téléchargements initiaux, au catalogue et aux mises à jour. Les requêtes envoyées aux modèles sont traitées par Ollama localement.

Dépannage

La première réponse prend du temps

C’est attendu après le lancement : Ollama doit charger le modèle en mémoire. Vérifiez ensuite dans les journaux que backend=nvidia, rocm ou vulkan apparaît si vous attendez une accélération GPU.

Linux utilise le CPU

Vérifiez que le pilote graphique et, pour NVIDIA, NVIDIA Container Toolkit fonctionnent sur l’hôte. Redémarrez ensuite Stellan.

Le moteur local n’est plus joignable

Fermez complètement Stellan, attendez quelques secondes puis relancez-le. Si le problème persiste, conservez les journaux avant de contacter le support.

Besoin d’aide

Écrivez à contact@takeos.fr avec votre système, la version Stellan et les dernières lignes du journal. Ne partagez jamais de clé privée ou de mot de passe.

Questions fréquentes

Stellan est-il gratuit ?

Oui. Les modèles locaux ne nécessitent pas d’abonnement à une API d’intelligence artificielle.

Dois-je installer Docker ?

Non. Stellan gère son propre runtime privé sous Windows et Linux.

Puis-je travailler sans internet ?

Les modèles déjà installés fonctionnent localement. Une connexion reste nécessaire au lancement pour la vérification obligatoire des mises à jour.

Une mise à jour retélécharge-t-elle mes modèles ?

Non. Les modèles sont stockés séparément de l’application.
